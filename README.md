# Mijia Desktop

Mijia Desktop（米家桌面控制中心）是面向 Windows 11 的米家设备控制应用。

> 本项目仅供作者本人个人使用，并非小米或米家官方产品，不提供面向公众的兼容性、
> 可用性或技术支持承诺。

## 主要功能

- 使用小米账号二维码登录；
- 展示、搜索、同步和刷新账号下的米家设备；
- 支持设备快速开关、属性调节和无需参数的 MIoT Action；
- 根据设备公开的 MIoT 能力动态生成通用控制界面；
- 为灯、智能插座、风扇和空调提供常用控制界面；
- 支持设备收藏、系统托盘和收藏设备快速控制；
- 操作成功后自动刷新目标设备状态；
- 支持浅色、深色及跟随系统主题；
- 支持开机启动、自动刷新、高级模式、重新登录和退出账号。

## 使用说明

### 系统要求

- Windows 11 64 位；
- 可正常访问小米云服务；
- 手机已安装米家 App，并可登录需要控制的账号。

### 下载与启动

1. 前往 [Releases](https://github.com/Edith-1204/MijiaDesktop/releases) 下载最新版本；
2. 可直接下载单文件 EXE，或下载并解压 `win-x64.zip` 发布包；
3. 双击 `MijiaDesktop-<版本号>.exe` 启动程序；
4. 若 Windows SmartScreen 提示未知发布者，请确认文件来源和 SHA-256 校验值后再决定
   是否运行。本程序目前没有商业代码签名。

### 登录米家

1. 首次启动后点击生成登录二维码；
2. 使用米家 App 扫描二维码并确认登录；
3. 登录成功后，程序会自动同步当前账号下的设备。

登录凭据使用 Windows DPAPI 加密，仅保存在当前 Windows 用户的数据目录中。发布包
不包含作者的账号、设备或登录信息。退出账号会清除本机保存的登录凭据。

### 设备控制

- 在“全部设备”中搜索、刷新或快速开关设备；
- 点击设备卡片进入详情页，查看并调整设备公开的可控属性；
- 点击收藏按钮后，可在“收藏”页面和系统托盘中快速访问设备；
- 控制成功后，程序会等待短暂时间并刷新该设备的完整状态；
- 米家吸顶灯 D30 已完成设备发现、详情显示和灯光控制验证；
- 其他设备的可用功能取决于设备型号公开的 MIoT 规格。

### 设置与退出

- 设置页可切换主题、调整自动刷新间隔、启用开机启动和高级模式；
- 可在设置页重新登录或退出当前米家账号；
- 点击窗口关闭按钮后，程序会隐藏到系统托盘；
- 如需完全退出，请使用托盘菜单中的“退出”。

## 使用限制

- 程序依赖小米云服务，不提供局域网离线控制；
- 摄像头画面、门锁敏感操作、自动化场景和蓝牙直连等专有能力不在支持范围内；
- 需要参数的 MIoT Action 不会直接执行；
- 部分设备的公开 MIoT 规格可能不完整，实际可用功能会因型号、固件和账号权限而异。
