# v0.1.0-alpha 已知问题

- 当前依赖小米云服务，不提供局域网离线控制；网络异常、设备离线或云端限流会导致
  状态刷新和控制失败。
- 不同型号公开的 MIoT 规格可能不完整或存在差异，部分属性可能只能读取，或无法由
  通用控件正确表达。
- 需要输入参数的 MIoT Action 在本版本中会显示为禁用，避免错误调用。
- 首次加载一个尚未缓存的设备型号时，需要下载 MIoT 规格，详情控件可能稍后才补全。
- Alpha EXE 尚未进行商业代码签名，Windows SmartScreen 可能显示未知发布者提示。
- 当前正式支持范围为 Windows 11 64 位；其他 Windows 版本尚未完成验收。

若设备控制失败，可在设置中开启高级模式，记录设备型号及相应 MIoT 标识，但不要
公开 DID、Token、Cookie、二维码或认证文件。
