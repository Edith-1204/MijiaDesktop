# 支持设备说明

Mijia Desktop 不维护固定型号白名单，而是读取设备公开的 MIoT Capability，按设备
实际提供的属性与 Action 动态生成界面。因此，“能够显示设备”不代表该设备的全部
厂商功能都可控制。

## 已完成专用界面的设备类别

- 灯：开关、亮度、色温及设备提供的其他灯光能力；
- 智能插座：电源开关及设备公开的其他属性；
- 风扇：开关、模式、风速等设备实际提供的能力；
- 空调及空调伴侣：开关、模式、目标温度、风速等设备实际提供的能力。

未归入以上类别的设备仍会进入通用详情页。Boolean、数值范围、枚举和只读属性可由
通用控件展示；无需参数的 Action 可以执行。

## 兼容性边界

- 实际可用能力取决于具体型号发布的 MIoT 规格、固件和账号权限；
- 摄像头画面、门锁敏感操作、自动化场景和蓝牙直连等专有能力不在本 Alpha 版本范围；
- 无法取得规格的设备仍可能显示在列表中，但不会提供完整控制项。
